Personal Oura Daily Report

This is a personal, non-commercial integration. It is used only by its owner to generate a personal daily report from their own Oura data. It is not a business service, it is not offered to the public, and it does not serve any other user.

Data accessed through the Oura API, with the owner's OAuth consent, is limited to the scopes needed for that daily report: daily summaries (sleep, readiness and activity), heart rate, SpO2 and workouts.

Privacy Policy

What is accessed. Only the owner's own Oura data, accessed through the Oura API with the owner's consent, for the purpose of generating a personal daily report.

What is not done. The data is not shared with any third party, not sold, not used for advertising, and not used for any business purpose.

Control. The owner can revoke access at any time from their Oura account. Revoking access stops any further access to Oura data.

Retention. Data is used to produce the daily report requested by the owner. No Oura data is published, and no health data is included on this page.

Terms of Service

Personal use only. This integration is for the personal use of its owner only. It is not a medical device, it does not provide medical advice, and its daily report is not a substitute for professional health advice.

Availability. Access depends on the owner's Oura account, Oura membership and the Oura API remaining available. The integration is provided as-is, with no warranty.

Ownership. Oura data remains the owner's data. Nothing in these terms transfers any right in Oura data to anyone else.
